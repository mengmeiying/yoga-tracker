# Йога-трекер

Одностраничный трекер для занятий йогой по YouTube-сериям. Нужен, чтобы попадать сразу в нужный урок, минуя ленту рекомендаций YouTube, и видеть, какие уроки уже пройдены.

Это один файл `index.html` без сборки и зависимостей. Хостится на GitHub Pages, отметки синхронизируются через приватный GitHub Gist.

## Что умеет

- **Карточки серий.** В каждой карточке следующий непройденный урок, кнопки «Начать» и «Сделала», прогресс и полный список уроков с заметками. Наверху стоят серии, которыми пользовались последними.
- **Открытие в приложении YouTube.** На Android кнопка «Начать» открывает видео сразу в приложении YouTube (через `intent://`), без браузерной версии и ленты.
- **Порядок уроков, а не календарь.** Уроки идут по номерам: пропустила день — просто делаешь следующий.
- **Кольца недели** (с понедельника по воскресенье), ориентир — рекомендации ВОЗ:
  - **Нагрузка:** 150 минут флоу и динамики.
  - **Сила:** 2 дня с силовыми уроками.
  - **Мягкая практика:** 60 минут растяжки и инь. Это своя цель: у ВОЗ здесь числа нет, есть только совет меньше сидеть.
- **Сетка привычек** в стиле Singularity. На широком экране показывает месяц, на узком неделю. Тап по кружку отмечает следующий урок серии этим днём, повторный тап снимает отметку.
- **Статистика за период:** практики, минуты, дни, самая частая серия.
- **Синхронизация с Gist.** Работает автоматически, история версий хранится в самом Gist.

## Установка

1. Положить `index.html` в корень репозитория.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту-две сайт появится по адресу `https://<ник>.github.io/<репозиторий>/`.
4. На планшете открыть адрес в Chrome, затем меню → «Добавить на главный экран».

## Синхронизация

1. Создать токен: GitHub → Settings → Developer settings → Personal access tokens → **Tokens (classic)**. Право нужно одно, `gist`, срок можно поставить без ограничения.
2. При первом открытии страницы вставить токен в окно «Синхронизация с GitHub». Страница сама найдёт или создаст Gist с файлом `yoga-tracker.json`.

Как это устроено:

- Отметки сначала пишутся в `localStorage`, а через пару секунд после изменения уходят в Gist.
- При открытии страницы и при возвращении на вкладку свежие данные подтягиваются из Gist. Конфликты решаются правилом «последняя запись побеждает».
- Токен хранится только в браузере устройства. В коде и в репозитории его нет.
- «Секретный» Gist не виден в поиске и профиле, но открывается по прямой ссылке.

Формат данных в Gist:

```json
{
  "updatedAt": 1762448400000,
  "done": { "<id урока>": "2026-11-06", "<id урока>": null },
  "used": { "<id серии>": 1762448400000 }
}
```

Пояснения к полям:

- `done` — пройденные уроки. Значение — дата прохождения или `null`, если урок пройден «раньше» и даты нет.
- `used` — когда серией пользовались последний раз. Отсюда берётся порядок карточек.

## Как поменять под себя

Все данные лежат в начале `<script>`, в массиве `SERIES`.

**Урок** — это массив:

```js
[id, номерДня, 'Название', 'мм:сс', ссылка, 'Заметка']
```

Что в нём:

- `номерДня: null` — бонусный урок. Он не входит в прогресс и не становится «следующим».
- `ссылка` — YouTube ID (можно с таймкодом: `'estt19oITfw&t=215'`) или полный адрес страницы. Если ссылки нет, YouTube ID берётся из `id`.
- `'мм:сс'` может быть `null`, если длительность неизвестна. Тогда урок не попадает в минуты.

**Тип урока для колец** задаётся на уровне серии:

```js
kind: 'soft',                            // тип по умолчанию для серии
kinds: { 5: 'load', 17: 'load+str' },    // исключения по номеру дня
```

Значения:

- `load` — минуты идут в «Нагрузку».
- `soft` — минуты идут в «Мягкую практику».
- `+str` — день засчитывается ещё и в «Силу».
- Вступления (день 0) и бонусы в кольца не идут.

**Цели колец** задаются в константе `GOALS`:

```js
const GOALS = { load: 150, strength: 2, soft: 60 };
```

**Новая серия** — это новый объект в `SERIES` с полями `id`, `name`, `author`, `color` и `lessons`. Цвет серии задаётся CSS-переменной в `:root`. Поле `dayWord` меняет подпись урока: по умолчанию «Day», для «Лопаток» стоит «День».

> Если делаешь форк для себя, очисти `DEFAULT_STATE`. Сейчас там отмечены первые уроки HOME.

## Источники рекомендаций

- [ВОЗ: физическая активность](https://who.int/initiatives/behealthy/physical-activity): 150–300 минут умеренной или 75–150 минут интенсивной активности в неделю, силовые 2 дня и больше.
- [Руководство ВОЗ 2020, глоссарий](https://https.ncbi.nlm.nih.gov/books/n/who336656/gl): определение силовой активности.

Разметка уроков по типам сделана на глаз по названиям и содержанию. Это ориентир, а не точный подсчёт по критериям ВОЗ.
